# BarFold v1.0 方案与实测记录

日期：2026-11-24
环境：macOS 26.4.1 (25E253)，Mac16,12 (Apple M4)，主屏 DELL U2725QE 1920×1080 + 内建 1470×956（safeAreaTop 32）

状态：核心 M0–M5 完成；M6 签名脚本/文档完成，固定证书待用户确认；M7 Sparkle 集成完成，appcast/升级链待密钥；M8 文档与开发包完成。

## 0. 背景

目标是做一个 iBar 的轻量替代：把菜单栏图标折叠到屏幕外，需要时用点击、悬停或热键展开。约束：

- 零权限优先：不申请辅助功能、屏幕录制、输入监控；
- 直接分发，不上架 App Store；
- 长期稳定：失败必须软着陆，不能把菜单栏留在异常状态；
- UX 优先：原生观感、设置窗/引导完整、可访问。

## 1. 相对最初方案的复核结论

1. **macOS 27 引擎不成立**：27 把菜单栏改成单窗口模型，长度撑开不再可靠。v1.0 删除未验证的 27 引擎，改为能力探测 + `UnsupportedEngine` + 明确提示；27 单独立项预研。
2. **悬停不能用全局事件监听**：全局 `NSEvent` 监听需要权限。改为 10Hz 轮询 `NSEvent.mouseLocation`，只在悬停功能开启且收起时运行。
3. **签名改为固定自签**：不做公证、不开 Hardened Runtime；用固定证书 + 临时钥匙串 + Sparkle EdDSA。证书只备份不重建。
4. **状态项顺序与位置是生命线**：创建前预置 `NSStatusItem Preferred Position`，箭头先建、分隔符后建；否则在已经溢出的菜单栏上，箭头会落在屏幕外。
5. **自动收回必须“武装”**：只在用户主动展开（点击/悬停/热键/菜单）后生效；启动恢复与 CLI expand 不武装，避免刚启动就自动收起。
6. **零权限 MVP 可行**：折叠、悬停、热键、多屏、登录启动都不需要 TCC。

## 2. M0 实测

### 2.1 iBar 干扰

用户当前使用 iBar。iBar 收起时，新建状态项被放在隐藏区：实测箭头 `x=-4188`，完全不可见。关闭 iBar 后同一测试恢复可见。结论：

- 开发/验收期间必须关闭 iBar；
- 正式使用只保留一个折叠工具；
- `barfold doctor` 检测 iBar/Hidden Bar/Ice/Bartender/Thaw/MenuTidy 并 warn。

### 2.2 位置预置与折叠

- 创建前写入 `NSStatusItem Preferred Position barfold_toggle=250`、`barfold_separator=265`（数值越大越靠左）。
- 箭头实测 `x=1621, y=1050, 26×30`，分隔符 `x=1597`，可见。
- 折叠：`separator.length=3840`，实际窗口宽 `3856pt`；canary 被推到 `x=-2321`（离屏）；可见状态窗口 `38 → 10`；箭头仍在 `x=1621`。
- 展开：canary 回 `x=1511`；可见窗口回到 `38`。
- 结论：`LengthSpacer` 在 macOS 26.4.1 上有效；`isCollapsed` 从长度派生；多屏按最宽屏计算。

### 2.3 菜单栏几何

- 主屏菜单栏高 30pt（`NSStatusBar.system.thickness` 报 22，不能直接用）。
- 刘海屏菜单栏高 33pt（safeAreaTop 32）。
- 悬停判定带取 `max(systemThickness, safeAreaTop+1, 30)`，并加 2pt 容差。

## 3. 架构

```
StatusItemController  箭头 + 分隔符 + canary
LengthSpacerEngine    separator.length = 折叠
CapabilityDetector    26.x / 27+ 能力探测
ProbeService          CGWindowList 几何 + doctor + selftest
HoverMonitor          10Hz mouseLocation，右半屏、非图标、非箭头
AutoCollapseController 菜单层 101 保护 + 延迟
HotkeyManager         Carbon RegisterEventHotKey
ControlServer         Unix socket JSON Lines，0600 + peer UID
CommandRouter         CLI 命令 / 自检
SettingsStore         UserDefaults + 校验
LoginItemManager      SMAppService → LaunchAgent
UpdateController      Sparkle 2，无密钥时惰性
Settings/Onboarding   SwiftUI + AppKit 窗口
```

## 4. CLI 契约

- 传输：`~/Library/Application Support/BarFold/control.sock`，JSON Lines，单请求单响应。
- 权限：socket `0600`，`LOCAL_PEERCRED` 校验 uid。
- 命令：`status/collapse/expand/toggle/probe/wait/settings/hotkey/engine/doctor/loginitem/update/selftest/logs/launch/quit`。
- 退出码：`0` 成功、`2` 用法、`3` 未运行、`4` 应用错误、`5` 超时。
- `probe` 是核心证据：箭头/分隔符窗口、屏幕、可见状态窗口数、canary、引擎校验。
- `wait` 同时等状态与几何稳定，避免“布尔已变、窗口还没动”的竞态。
